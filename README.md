# T02. ELDI COIN
[실행 사이트](https://eldi96.github.io/T02_eldi-coin/)
**ELDI COIN**은 가상의 코인 시장에서 위험과 보상을 선택하는 브라우저 미니게임입니다. 코인을 유지하며 다음 날로 진행할지(**HOLD**), 현재 보유량을 확정할지(**CASH OUT**) 결정합니다.

> 실제 가상자산 거래나 투자 서비스가 아닌 교육용 게임입니다. 표시되는 코인과 시장 변화는 게임 내 가상 값입니다.

## 주요 기능

- 시작 코인 **10**에서 게임 진행
- **HOLD / CASH OUT** 선택
- **x1 / x2 / x5 / x10** 배율 선택
- 현재 코인, 증감률, 최고 기록, 위험도 표시
- Canvas 기반 시장 그래프와 변화 애니메이션
- 결과 화면 및 다시하기
- 브라우저 `localStorage`를 이용한 최고 기록 보관
- 사운드 및 전체 화면 버튼

## 사용 기술

HTML, CSS, JavaScript, Canvas API, localStorage를 사용했습니다. 별도의 프레임워크나 빌드 과정 없이 브라우저에서 실행하는 정적 게임입니다.

## 실행 방법

1. 저장소를 내려받거나 복제합니다.
2. 프로젝트 루트의 `index.html`을 브라우저에서 엽니다.
3. 배율을 선택한 뒤 **HOLD** 또는 **CASH OUT**으로 게임을 진행합니다.
4. 결과 화면에서 **다시하기**를 눌러 새 게임을 시작할 수 있습니다.

## 게임 규칙과 데이터

배율에 따라 상승·하락 확률과 변화 폭이 다르게 설정되어 있습니다. 게임의 수치와 그래프는 `game.js`에서 처리하며 외부 시세 API를 사용하지 않습니다.

최고 기록은 현재 브라우저의 `localStorage`에 저장되므로 다른 브라우저나 기기와 자동으로 공유되지 않습니다.

## 상태

현재 저장소의 HTML·JavaScript·파일 구성을 기준으로 작성한 설명입니다. 모든 브라우저에서의 동작이나 배포 상태를 검증 완료로 주장하지 않습니다.
